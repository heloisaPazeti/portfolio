# Système de Dialogue avec Unity

Un petit projet développé avec Unity et C# qui explore l'implémentation d'un système de dialogue réutilisable pour les jeux interactifs.

Le projet se concentre sur l'organisation des données de dialogue et le contrôle du déroulement des conversations entre le joueur et les personnages du jeu.

## Fonctionnalités

* Dialogues séquentiels
* Gestion des états des dialogues
* Interaction avec les personnages
* Composants de dialogue réutilisables
* Contenu des dialogues configurable

## Technologies

* Unity
* C#

## Objectif

Ce projet a été créé comme une expérimentation ciblée sur l'implémentation de systèmes de dialogue indépendamment des autres mécaniques de gameplay.

L'objectif était d'explorer comment séparer les données de dialogue de la logique du jeu afin de faciliter la réutilisation du système dans différentes interactions.

## Améliorations Futures

* Ajouter des choix et des embranchements dans les dialogues
* Externaliser les données de dialogue
* Ajouter des événements de dialogue
* Prendre en charge plusieurs personnages
* Améliorer les outils de configuration dans l'éditeur Unity
