# Sistema de Diálogos na Unity

Um pequeno projeto em Unity/C# que explora a implementação de um sistema de diálogos reutilizável para jogos interativos.

O projeto tem como foco a organização dos dados de diálogo e o controle do fluxo das conversas entre o jogador e os personagens do jogo.

## Funcionalidades

* Diálogos sequenciais
* Gerenciamento de estados dos diálogos
* Interação com personagens
* Componentes de diálogo reutilizáveis
* Conteúdo de diálogo configurável

## Tecnologias

* Unity
* C#

## Objetivo

Este projeto foi criado como um experimento focado na implementação de sistemas de diálogo de forma independente de outras mecânicas de gameplay.

O objetivo foi explorar como os dados de diálogo e a lógica do jogo podem ser separados para facilitar a reutilização do sistema em diferentes interações.

## Melhorias Futuras

* Externalizar os dados de diálogo
* Adicionar eventos de diálogo
* Implementar suporte a múltiplos personagens
* Aprimorar as ferramentas de configuração pelo Editor
