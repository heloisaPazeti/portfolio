# SpaceWar

Um pequeno **jogo 2D de corrida espacial / endless runner**, desenvolvido na Unity como um experimento pessoal com mecânicas de gameplay.

O projeto explora a implementação de um ciclo simples de jogo no estilo arcade e também foi publicado como uma versão jogável no itch.io.

## Gameplay

O jogador controla uma nave espacial enquanto navega por um ambiente espacial gerado infinitamente.

O projeto tem como foco a experimentação com:

* movimentação do jogador;
* desvio de obstáculos;
* gameplay contínuo;
* progressão do jogo;
* mecânicas de jogos no estilo arcade.

## Tecnologias

* Unity
* C#

## Objetivo

Este projeto foi desenvolvido como um experimento pessoal para praticar Unity e C#, construindo um jogo completo e jogável em vez de implementar apenas mecânicas isoladas.

## O Que Aprendi

* Implementação de mecânicas de gameplay na Unity
* Estruturação de um pequeno projeto de jogo
* Desenvolvimento de um ciclo contínuo de gameplay
* Criação e teste de uma versão jogável do jogo
