# Structures de Données en C

Un ensemble de **structures de données et d'exercices de programmation associés, implémentés en C**, réalisés dans le cadre de mes études en structures de données.

Ce dépôt contient des implémentations de structures de données fondamentales, ainsi que de petits projets mettant en pratique ces structures pour résoudre des problèmes concrets.

## Structures Implémentées

### Listes

* Listes simplement chaînées
* Listes doublement chaînées
* Listes doublement chaînées circulaires

### Files

* Files statiques
* Files dynamiques

### Piles

* Piles statiques
* Piles dynamiques

### Arbres

* Arbres Binaires de Recherche (ABR / BST)
* Arbres AVL
* Arbres Rouge-Noir (Red-Black Trees)
* Arbres Binaires

### Graphes

* Graphes stockés dans des fichiers binaires

### Fichiers Binaires

* Manipulation de fichiers binaires

## Projets Appliqués

Le dépôt contient également des projets utilisant les structures de données implémentées, notamment :

* Éditeur de texte
* Comparaison entre AVL et BST
* Gestion de tags à l'aide d'un BST
* Gestion de tags à l'aide d'un AVL

## Technologies

* C
* Pointeurs
* Allocation dynamique de mémoire
* Manipulation de fichiers
* Structures de données et algorithmes

## Objectif

Ce dépôt présente mes implémentations et mes exercices pratiques autour des structures de données fondamentales en C, en mettant l'accent sur la compréhension de leur organisation interne plutôt que sur l'utilisation d'implémentations fournies par des bibliothèques.
