# Estruturas de Dados em C

Uma coleção de **estruturas de dados e exercícios de programação relacionados, implementados em C**, desenvolvidos como parte dos meus estudos em Estruturas de Dados.

O repositório contém implementações de estruturas de dados fundamentais, além de pequenos projetos que aplicam essas estruturas a problemas práticos.

## Estruturas Implementadas

### Listas

* Listas simplesmente encadeadas
* Listas duplamente encadeadas
* Listas duplamente encadeadas circulares

### Filas

* Filas estáticas
* Filas dinâmicas

### Pilhas

* Pilhas estáticas
* Pilhas dinâmicas

### Árvores

* Árvores Binárias de Busca (BST)
* Árvores AVL
* Árvores Rubro-Negras (Red-Black Trees)
* Árvores Binárias

### Grafos

* Grafos em arquivos binários

### Arquivos Binários

* Manipulação de arquivos binários

## Projetos Aplicados

O repositório também contém projetos que utilizam as estruturas de dados implementadas, incluindo:

* Editor de texto
* Comparação entre AVL e BST
* Gerenciamento de tags utilizando BST
* Gerenciamento de tags utilizando AVL

## Tecnologias

* C
* Ponteiros
* Alocação dinâmica de memória
* Manipulação de arquivos
* Estruturas de dados e algoritmos

## Objetivo

Este repositório documenta minhas implementações e práticas com estruturas de dados fundamentais em C, com ênfase na compreensão de sua organização interna, em vez de depender de implementações fornecidas por bibliotecas.
