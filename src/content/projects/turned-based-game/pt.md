# Jogo por Turnos na Unity

Um pequeno **projeto de aprendizado em Unity/C#**, desenvolvido para explorar a implementação de um sistema básico de combate por turnos.

O projeto foi desenvolvido acompanhando um tutorial da Brackeys e utilizado para experimentar a estrutura fundamental de um sistema de combate por turnos na Unity.

## O que explorei

* Fluxo de combate por turnos
* Ações dos personagens
* Ações dos inimigos
* Gerenciamento básico dos estados de combate
* Programação utilizando Unity/C#

## Tecnologias

* Unity
* C#

## Objetivo

Este repositório é principalmente um exercício de aprendizado e um registro dos meus primeiros experimentos com sistemas de gameplay por turnos.
