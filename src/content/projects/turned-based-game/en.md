# Unity Turn-Based Game

A small **Unity/C# learning project** created to explore the implementation of a basic turn-based combat system.

The project was developed while following a Brackeys tutorial and was used to experiment with the fundamental structure of turn-based combat in Unity.

## What I Explored

* Turn-based combat flow
* Character actions
* Enemy actions
* Basic combat state management
* Unity/C# scripting

## Technologies

* Unity
* C#

## Purpose

This repository is primarily a learning exercise and a record of my first experiments with turn-based gameplay systems.
